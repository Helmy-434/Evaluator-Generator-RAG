      How it works

      1. Generator answers your question using only the sources you added.
      2. Evaluator checks the answer for accuracy, relevance, completeness and grounding.
      3. If it is rejected, the feedback goes back to the Generator for a better answer, for up to 4 rounds.
      4. If the question cannot be answered from your sources, you are told so instead of getting a guess.
